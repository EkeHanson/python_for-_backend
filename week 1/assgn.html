Question 1: Temperature Converter (5 marks)

Write a program that:

  • Takes a temperature in Celsius as input from the user
  • Converts it to Fahrenheit using the formula: F = (C × 9/5) + 32
  • Displays the result
Solution: celsius = float(input("Enter temperature in Celsius: ")) fahrenheit = (celsius * 9/5) + 32 print(f"{celsius}°C is equal to {fahrenheit}°F")

Question 2: Name Formatter (5 marks)

Write a program that:

  • Asks the user for their first name and last name
  • Capitalizes the first letter of each name
  • Prints the formatted full name
Solution: first_name = input("Enter your first name: ") last_name = input("Enter your last name: ") first_name = first_name.lower().capitalize() last_name = last_name.lower().capitalize() print(f"Your full name is: {first_name} {last_name}")

Write a program that:

  • Takes a URL as input (e.g., "www.google.com")
  • Extracts and prints only the domain name (e.g., "google")
  • Hint: Use string slicing

Question 5: Right-Angle Triangle Hypotenuse (10 marks)

Write a program that:

  • Takes the lengths of the opposite and adjacent sides as input
  • Calculates the length of the hypotenuse using the Pythagorean theorem: c = √(a² + b²)
  • Uses the math module
  • Displays the result with a descriptive message
Solution: import math opposite = float(input("Enter the length of the opposite side: ")) adjacent = float(input("Enter the length of the adjacent side: ")) hypotenuse = math.sqrt((opposite ** 2) + (adjacent ** 2)) print(f"The length of the hypotenuse is: {hypotenuse}")

Part F: Short Answer 10 marks

1. What is the difference between math.floor() and math.ceil()?

Answer: math.floor() rounds a number down to the nearest integer. math.ceil() rounds a number up to the nearest integer. Example: math.floor(4.9) → 4 math.ceil(4.1) → 5

2. Explain what type casting is and give two examples.

Answer: Type casting is converting a value from one data type to another. Examples: 1. int("123") → converts string to integer (123) 2. str(456) → converts integer to string ("456")

3. What is the difference between print() and input()?

Answer: print() is used to display output to the console. input() is used to receive input from the user and always returns a string.

4. What is string indexing? Provide an example.

Answer: String indexing is accessing individual characters in a string using their position (index), starting from 0. Example: name = "Python" name[0] → "P" name[3] → "h"

5. What is a docstring and how is it written?

Answer: A docstring is a multi-line string used to document code. It's written using triple quotes (""" or '''). Example: """ This is a docstring It can span multiple lines Used for documentation """
